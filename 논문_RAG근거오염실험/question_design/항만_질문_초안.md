# 항만 질문 세트

`experiment.py`가 읽는 질문 세트. 4열 형식: `| 질문 | 답 있음/없음 | 항구 | 참고 문서 |`

오염 실험이 의미를 가지려면 질문마다 **특정 항구**가 지정되어 있어야 함
(공통 문서는 오염 대상이 아니므로 제외 — CLAUDE.md 참고).

**변경 이력**
- 2026-09-09: 부산항 전용 문서가 8청크뿐으로 다른 항구(울산항 243, 대산항 167, 인천항 59) 대비
  최대 30배 적어 오염 실험 조건이 이질적이라고 판단, 부산항 질문을 제외하고 울산항/대산항/인천항
  3개 항구로 좁힘 (멘토 확인 완료). 부산항 문서 자체는 삭제하지 않고 다른 항구 질문의 오염 청크
  후보 풀로 계속 사용함.
- 2026-09-09: `find_gold_chunks.py`로 전수 검증한 결과 2건의 문제 발견 후 조치.
  - "대산항 대리점·라인맨 휴대품" 질문 — 정답 근거가 실제로 top-10 밖(10등)에서 나와 검색
    신뢰도가 낮다고 판단, 제외.
  - "인천항 화재 최초 발견자" 질문 — 정답 문구가 참고 문서(인천항 재난대응 프로세스) 어디에도
    없음을 확인 (해당 문서는 개인 행동요령이 아니라 조직/단계별 대응 매뉴얼). 원문에 실제로
    있는 내용("재난대응 단계 구분")으로 교체.
- 2026-09-11: 팀원이 원문 대조로 전수 재검증한 결과 "울산항 크레인 작업 시 확인해야 할
  안전사항" 질문의 정답이 부분 조작(진짜 근거 1개 + 다른 맥락에서 온 부정확한 인용 2개 +
  원문에 없는 완전 날조 1개)으로 확인됨. 이 문서에 "크레인 작업" 전용 장이 없어 화물별 장에
  내용이 흩어져 있는 게 원인 — 질문 범위를 좁혀 원문(c6)에 그대로 있는 내용으로 교체.
  "대산항 접현등" 질문 답변의 "항과 선박이"(오변환)도 "航過선박(지나가는 선박)이"로 수정.
  이후 사용자가 재확인한 결과, 이 새 q3 정답도 원문의 서로 다른 두 불릿포인트("시험운전으로
  확인한다" / "정기검사 필한 장비만 사용한다")를 하나로 합쳐 어미까지 바꾼 상태였음을 발견 —
  안전하게 첫 번째 불릿포인트 하나만 원문 그대로 남기는 것으로 재수정.
- 2026-09-11: 파일럿 스모크 테스트 결과 L0(오염 0%)에서도 정답이 하나도 안 나와 원인 조사 —
  q1·q2의 gold_chunk_id가 자동 키워드 매칭의 오탐이었음을 발견(둘 다 스팟체크 없이 채택된
  상태였음). q1은 진짜 근거 청크(c56)로 정정. q2는 원래 정답 문구("9개 화물별 작업을
  다룬다...")가 청킹된 코퍼스 어디에도 존재하지 않음을 확인(전처리 중 빠진 서문으로 추정) —
  슬라브 작업 장비·도구를 묻는 질문으로 완전 교체.
  이 과정에서 "정답 근거가 검색 자연 순위 top-2 안에 들어야 한다"는 기존 기준을 폐기함 —
  단계적 오염 설계(build_graduated_context)가 정답 근거를 자연 순위와 무관하게 항상 강제로
  고정하므로 자연 순위는 더 이상 실험 타당성에 영향을 주지 않음. 대신 "gold_chunk_id의
  내용이 원문과 정확히 일치하는가"만을 채택 기준으로 삼음.

현재 3개 항구(울산항/대산항/인천항), 답변가능 11문항 + 함정 3문항, 총 14문항.
