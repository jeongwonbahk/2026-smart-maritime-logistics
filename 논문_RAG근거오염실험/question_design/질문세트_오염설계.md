# 오염 설계 질문세트 (11문항) — 크로스체크용

작성일: 2026-09-20

## 이게 뭔가

기존 오염 실험에서 **오염 근거가 너무 명백하게 무관해서** 모델이 쉽게 걸러냈다.
그 결과 오염을 0개에서 4개까지 늘려도 오답률이 안 올라갔다 (L0 5.5% → L4 0.3%).

예를 들어 "크레인 주요 구조물에 몇 ㎜ 철판을 쓰면 안 되나"라는 질문에
오염으로 들어간 건 울산항 매뉴얼의 "스링이 훅에서 빠질 위험" 같은 내용이었다.
크레인 얘기긴 해도 **질문에 대한 답처럼 보이는 구석이 전혀 없다.**

그래서 이번엔 **진짜 헷갈릴 만한 오염 근거**로 다시 테스트한다. 조건은:

- 정답 근거와 **같은 문서** 안에 있을 것 (항구 오염과 섞이지 않게)
- 어휘·문장구조가 비슷할 것
- **같은 단위의 숫자가 서로 다를 것** (정답/오답이 명확히 갈리도록)
- 단, **그 질문의 답은 아닐 것** ← 가장 중요

## 어떻게 찾았나

`find_confusable_pairs.py` — 실험이 쓰는 것과 같은 임베딩 모델
(`jhgan/ko-sroberta-multitask`)로 문서 내 청크 쌍의 유사도를 계산하고,
같은 단위의 숫자가 충돌하는 쌍만 필터링 → 97쌍 후보
(`confusable_pairs_report.txt`) → **전부 원문 확인 후 손으로 선별**.

자동 순위는 믿지 않았다. 실제로 Q1에서 자동 순위 1위는 "계단 폭 560㎜"(무관)였고,
진짜 강한 방해 근거인 "철판 두께 25㎜"는 7위로 밀려 있었다. 임베딩 유사도는
"주제가 비슷한가"는 잡아도 "답처럼 보이는가"는 못 잡는다.
(예전 `find_gold_chunks.py`가 자동 매칭만 믿었다가 q1·q2 gold_chunk_id를 틀린 것과 같은 함정)

## 방해 근거가 5개씩인 이유

기존 실험의 레벨 구조를 그대로 재현하기 위해서다.

| 레벨 | 근거 5칸 구성 |
|---|---|
| L0 | 정답 + 정상 4 |
| L1 | 정답 + **방해 1** + 정상 3 |
| L2 | 정답 + **방해 2** + 정상 2 |
| L3 | 정답 + **방해 3** + 정상 1 |
| L4 | 정답 + **방해 4** |
| L5 | **정답 없음** + **방해 5** |

방해 근거는 **강한 것부터** 순서대로 쌓인다(L1 ⊂ L2 ⊂ L3 ⊂ L4 ⊂ L5).
기존 `build_graduated_context()`도 오염 후보를 유사도 순으로 정렬해 `[:level]`로
잘라 쓰므로, 구조가 동일해서 **레벨끼리 직접 비교**가 가능하다.

**1순위는 "같은 속성인데 숫자만 다른" 강한 방해**이고, 2순위 이하는 점점 약해진다.
아래 각 문항에 **강/중/약**으로 표시했다.

## 크로스체크 부탁하는 것

문항마다 세 가지만 봐주면 된다.

1. **원문이 진짜 그렇게 적혀 있나** (PDF에서 해당 조항 찾아 대조)
2. **방해 근거가 정말 이 질문의 답이 아닌 게 맞나** ← 답이 될 수 있으면 실험이 깨짐
3. **질문이 정답 하나만 가리키나**

**2번은 1순위(강)만 집중해서 봐주면 된다.** 2~5순위는 "적어도 이 질문의 답은
아니다"만 확인하면 충분하다.

아래 원문은 ChromaDB 청크 내용을 **그대로** 옮긴 것이다. PDF 원본과 띄어쓰기가
다를 수 있는데(변환 과정에서 깨진 부분) 그건 청크 쪽 문제라 실험에 영향이 없다.
**숫자와 내용**만 맞는지 봐주면 된다.

## 실험에서 쓸 방식

- 정답 근거와 방해 근거를 **chunk_id로 직접 고정**해서 컨텍스트에 넣는다
  (검색으로 "찾아진" 오염이 아니라 **설계된** 오염). → `distractor_chunk_ids.csv`
- 레벨 L0~L5는 기존 본실험과 동일 구조, 프롬프트도 P0/P1 그대로, 반복 30회.
- 측정 두 가지 병행:
  1. **4단계 채점** (정답/근거초과/기권/오답) — LLM 판정
  2. **충돌 키워드 문자열 검사** — 답변에 방해 근거의 숫자(예: "25㎜")가 들어갔는지.
     방해 근거를 우리가 직접 지정했기에 가능한 객관 지표이며, LLM 판정에 의존하지 않는다.
